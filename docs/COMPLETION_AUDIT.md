## Known gaps (honest ledger)

- Playwright E2E/visual stack (Phase 1/7 gap) remains unbuilt; browser coverage today is rendered-HTML tests plus live manual verification.
- Observability depth (JSON logs/metrics/traces beyond the admin endpoint), container image scanning, and provenance attestation remain unbuilt.
- The Phase 8 audit's 24 lower-priority findings (recorded in docs/PROGRESS.md, 2026-08-25 entry) include open hardening items: production NATS has no auth, coordinator/worker lack healthchecks, Scout containers run as root, robots.txt checks are skipped on redirect hops, and the internal HMAC assertion covers method/path/user but not the request body.

Before completion, every row above must be `Complete` with exact code, test, runtime, or operational evidence. Any uncertain row remains incomplete.
